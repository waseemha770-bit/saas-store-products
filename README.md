# منصة تاجر-جو (TajerGo SaaS) 🚀

منصة تجارة إلكترونية سحابية خفيفة وسريعة (SaaS)، مصممة لتمكين رواد الأعمال والتجار من إطلاق متاجرهم الإلكترونية فوراً.
تم تطوير هذه المنصة وهندستها لتكون متعددة المستأجرين (Multi-tenant) مع تقليل تكاليف التشغيل إلى الصفر بالاعتماد على أدوات لامركزية.

## التقنيات المستخدمة:
* **Backend:** Python / Flask
* **Frontend:** HTML5, CSS3, Bootstrap 5 (RTL - Cairo Font)
* **Database:** Google Sheets (عبر استدعاء CSV ذكي)
* **Hosting:** Vercel (Serverless)

## الميزات التقنية:
- توليد مسارات المتاجر ديناميكياً لكل تاجر.
- خوارزمية ذكية لربط أعمدة قاعدة البيانات (Smart Column Mapping) لتفادي انهيار النظام.
- معالجة ذكية لروابط Google Drive وتحويلها لروابط صور مباشرة.
- دمج سلس للطلبات المباشرة عبر WhatsApp.
