# 🛒 منصة المتاجر الذكية (SaaS E-commerce Platform)

منصة متكاملة تتيح للتجار إنشاء وإدارة متاجرهم الإلكترونية بسهولة، مع نظام متقدم لإدارة الطلبات، التوصيل، والتكامل المباشر مع واتساب.

## ✨ المميزات الرئيسية
- 🏪 **متاجر متعددة (SaaS):** بنية تحتية تدعم آلاف المتاجر على منصة واحدة.
- 📱 **متوافق مع الجوال (PWA):** تصميم متجاوب يعمل كتطبيق على هواتف العملاء والتجار.
- 🛵 **بوابة المناديب:** نظام خاص بكل مندوب لاستلام الطلبات وتأكيد التوصيل بضغطة زر.
- 💬 **الطلب عبر واتساب:** تحويل سلة المشتريات إلى رسالة واتساب منسقة تصل للتاجر فوراً.
- ⚡ **أداء فائق:** استضافة Serverless على خوادم Vercel لضمان سرعة الاستجابة.

## 🛠️ التقنيات المستخدمة
- **Python / Flask**
- **Bootstrap 5**
- **Vercel Serverless**

## 📂 هيكلية الملفات الأساسية
- `app.py`: القلب النابض للمنصة وموجه الطلبات (Router).
- `database.py`: مدير قاعدة البيانات وحفظ السجلات.
- `vercel.json`: إعدادات التوجيه المتقدمة لتخطي قيود الاستضافة.
- `templates/`: واجهات المستخدم (لوحة التحكم، المتجر، بوابة المندوب).
