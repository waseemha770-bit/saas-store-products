# TajerGo (تاجر جو) - SaaS Store Builder

منصة SaaS متعددة المستخدمين (Multi-Tenant) تتيح للتجار إنشاء متاجر إلكترونية بسيطة، تم بناؤها باستخدام Python و Flask و Google Sheets لتعمل بتكلفة $0.

## المميزات
- **تعدد المستخدمين:** كل تاجر يحصل على متجر خاص برابط مستقل (مثال: `/store/admin-store`).
- **قاعدة بيانات مجانية:** قراءة البيانات بالكامل عبر ملف Google Sheets (CSV) واحد.
- **عزل البيانات:** التاجر يرى منتجاته وطلباته فقط.
- **التكلفة $0:** متوافق تماماً مع الاستضافة المجانية لـ Vercel وخوادم GitHub.

## هيكل البيانات (Google Sheets)
النظام يقرأ البيانات من ورقة عمل واحدة مدمجة باستخدام عمود `DataType` لتصنيف الصفوف إلى: `user`, `product`, `setting`.

## تعليمات النشر على Vercel
1. قم برفع كافة ملفات المشروع إلى مستودع GitHub الخاص بك.
2. توجه إلى منصة [Vercel](https://vercel.com) وقم بتسجيل الدخول باستخدام GitHub.
3. اضغط على `Add New` -> `Project`.
4. اختر المستودع الخاص بالمشروع واضغط `Import`.
5. سيتعرف Vercel تلقائياً على ملف `vercel.json` ويقوم بتثبيت `requirements.txt`.
6. اضغط `Deploy`!

## التطوير المستقبلي
النسخة الحالية توفر إمكانية "العرض" (Read-Only) من خلال Google Sheets بصيغة CSV لتجاوز حجب Google Cloud API. لإضافة ميزات الإدخال (الكتابة)، سيتم دمج قاعدة بيانات مثل PostgreSQL لاحقاً.
