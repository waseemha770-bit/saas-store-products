دليل الربط السحابي للصور
الحصول على مفتاح ImgBB (موصى به ⭐)
1 افتح موقع: api.imgbb.com وأنشئ حساباً.
2 اضغط على Add API Key والصق الرمز الطويل في إعدادات متجرك.
الحصول على مفتاح Imgur
1 أنشئ حساباً مجانياً في: imgur.com
2 سجل تطبيقاً: api.imgur.com/addclient للحصول على Client ID والصقه.
الحصول على مفتاح Postimages.org
1 افتح الموقع وقم بتسجيل الدخول: postimages.org
2 توفر المنصة ميزة الـ API للحسابات المتميزة (Premium) أو عبر طلب مفتاح مطور من الدعم.
3 بمجرد حصولك على الـ API Endpoint أو الـ Key، قم بلصقه في الإعدادات.

ملاحظة: لسهولة البدء المجاني 100% بدون تعقيدات، ننصحك باستخدام منصة ImgBB.

ربط Cloudinary (المنصة الاحترافية 🚀)
1 أنشئ حساباً في Cloudinary.com وانسخ Cloud Name.
2 من الإعدادات (Settings -> Upload) أضف Upload Preset واجعله Unsigned.
3 انسخ الكلمتين وضعهما في إعدادات المتجر!
