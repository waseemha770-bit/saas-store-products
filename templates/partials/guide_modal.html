دليل الربط السحابي للصور
شرح منصة Catbox.moe (الخيار الأسهل والافتراضي):
1 مجانية بالكامل وتسمح برفع صور بحجم يصل لـ 200 ميجابايت.
2 لا تحتاج لأي تسجيل دخول أو مفاتيح API أبداً!
3 فقط اخترها من القائمة واضغط حفظ، وستعمل فوراً.
خطوات ربط منصة ImgBB:
1 افتح موقع api.imgbb.com وقم بتسجيل الدخول.
2 اضغط على زر Add API Key لتحصل على الرمز السري.
3 انسخ الرمز الطويل، ثم ارجع هنا والصقه في خانة (مفتاح الربط API Key).
تنبيه: هذه المنصة قد تكون محظورة في بعض الدول، إذا فشل الرفع استخدم Cloudinary.
شرح منصة FreeImage.host:
1 سجل حساب في freeimage.host.
2 اذهب لصفحة الـ API وانسخ الرمز السري والصقه في خانة مفتاح الربط.
خطوات ربط منصة Imgur:
1 سجل حساباً في imgur.com.
2 اذهب إلى صفحة إنشاء تطبيق جديد.
3 اختر OAuth 2.0 authorization without a callback URL.
4 سيظهر لك Client ID، انسخه والصقه في خانة (مفتاح الربط).
معلومات منصة Postimages:
1 افتح موقع postimages.org.
2 تتطلب هذه المنصة أحياناً مراسلة الدعم للحصول على مفتاح API خاص.
💡 ملاحظة: كبديل سريع، يمكنك رفع الصور لديهم يدوياً ونسخ الرابط المباشر للصورة، ثم وضعه في حقل إضافة المنتج مباشرة.
خطوات ربط Cloudinary (الخيار الأفضل والمضمون 100%):
1 سجل حساباً مجانياً في Cloudinary.com.
2 من لوحة التحكم الرئيسية، انسخ اسم السحابة الخاص بك Cloud Name.
3 اذهب إلى الإعدادات Settings ⚙️ (أسفل اليسار) ثم اختر Upload.
4 انزل لأسفل واضغط على الرابط الأزرق Add upload preset.
5 اجعل خيار Signing Mode يساوي Unsigned واضغط حفظ.
6 انسخ اسم الـ Preset الذي ظهر لك، والصقه مع الـ Cloud Name في إعدادات متجرك!
